Project Status

Where the Metal Edge site stands today — the launch plan, what's still open, and a log of what's been built so far.

Launch Plan

Goal: ship the new site ASAP, then keep improving.

The priority right now is getting the new Metal Edge site live so it can start representing the brand and capturing leads. We're intentionally trimming scope on anything that isn't strictly needed for launch.

Most visibly: the Tools section (Submittal Wizard, Color Visualizer, BIM & CAD Library) is hidden by default. It's not deleted — it stays live behind ?showtools=true for internal review — but it's pulled from the public site, the nav, and the footer so we can launch without waiting on those features to be finished. We'll re-enable and expand them in subsequent rounds.
